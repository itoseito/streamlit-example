# 注文が来たときの流れ（サンタ動画）

1. Stripeの「取引」で、成功した支払いを確認（メールアドレスをメモ）
2. Googleフォームの回答で、同じメールアドレスの回答を探す
   - 呼び名が読みにくい・不適切な内容 → 制作前にメールで確認
   - フルネーム・学校名などが書かれていたら、使わない
3. Claudeに「注文番号・呼び名・がんばったこと」を伝えて作ってもらう
   `python3 santa/make_order.py <番号> <呼び名> <がんばったこと>`（クレジット0・約1分）
4. 自分で最後まで見て、名前の読み方・字幕・音を確認
5. 下の文面でメール送信（動画を添付。大きければGoogleドライブの共有リンク）
6. 記録：支払い日時／入力日時／納品日時／作業時間（分）／作り直し回数
7. 納品から30日後：フォームの回答と動画ファイルを削除

## 納品メールの文面
件名：サンタからのビデオメッセージをお届けします

【お名前】様

このたびはご注文ありがとうございました。
【呼び名】へのサンタからのビデオメッセージができあがりましたので、お届けします。

（動画ファイルを添付／共有リンク：【URL】）

名前の読み方などに誤りがあれば、このメールにご返信ください。無料で作り直します。
いただいた呼び名とエピソードは、納品から30日後に削除します。
