# ファスナー v2　投稿文

タイトル：
引くだけで閉じる。ファスナーの中は何が起きてる？

説明欄（ここからコピー）：

ファスナーを動かす小さな部品「スライダー」。
中にあるY字の通り道が、左右の歯をななめに寄せてはめたり、くさびで押し分けて外したりしています。
いつもの開け閉めを、オリジナルの図解でのぞいてみました。

TRY LOG｜いつもの世界に、知らなかった仕組み。

参考：YKK「ファスナーの仕組み」
https://www.ykk.com/ykk/tech/01.html

音声：VOICEVOX:四国めたん

※歯の形状と動きを簡略化した模式図です。実際の歯は、かみ合うための細かな形状を持っています。
