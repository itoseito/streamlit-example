# 飛行機の窓 v2　投稿文

タイトル：
飛行機の窓は、なぜ角が丸い？

説明欄（ここからコピー）：

旅客機の窓の丸みには、安全のための理由があります。
空気を詰めた機体の壁にかかる力と、四角い角に力が集まりやすいことを、オリジナルの図解で紹介します。
